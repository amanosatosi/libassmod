The generated tiny TrueType fixtures are original rectangle fonts, distributed
under the repository's ISC license. No data was copied from MUA Better or any
other font. Regenerate them with `python3 generate-decoration-fonts.py`; the
generator uses only the Python standard library and is not needed by CI.

| Family | UPEM | Cell height | Underline position/thickness | Strikeout position/thickness | Coverage |
| --- | ---: | ---: | --- | --- | --- |
| Deco Primary A | 2048 | 2048 | -900 / 100 | 600 / 128 | space, A, C |
| Deco Primary B | 1000 | 1000 | -150 / 240 | 400 / 200 | space, A, C |
| Deco Fallback | 1000 | 1500 | -100 / 400 | 40 / 300 | space, B, 〈, 〉 |
| Deco Complete | 2048 | 2048 | -900 / 100 | 600 / 128 | all of the above |

The different fallback cell height also detects scaling decoration metrics with
the glyph face's scale. Advances and rectangle ink are normalized to the cell
height, giving predictable probes for both simple and complex shaping.

The same generator also creates two original ruby clearance fixtures (ISC):
`furi-tight-ascent.ttf` has ascent/descent 250/750 but ink from 0 to 500;
`furi-tight-descent.ttf` has ascent/descent 900/100 but ink from -400 to 100.
Both use UPEM/cell height 1000 and cover space, W, M, 漢字, かんじ and all
characters in the 認めていた臆病な過去 horizontal-accommodation regression
(including its readings). The visible rectangle therefore exceeds one nominal
vertical metric. The furigana geometry tests run with each family explicitly
selected, covering both annotation sides and horizontal geometry in both
`\furichangepos` modes 0, 1, and 2.

Both tight fonts also cover every codepoint in `ဆာတို့` and `စူဇူကီ`:
U+1000, U+1005, U+1006, U+1007, U+1010, U+102C, U+102D, U+102E,
U+102F, U+1030, U+1037. Nonspacing marks have zero advance, width 125,
height 200, and left bearing -125. U+102F/U+1030/U+1037 ink is below the
rectangle baseline; U+102D/U+102E ink is above its top. U+102C is a spacing
vowel with the ordinary 500-unit advance. Base rectangles and the deliberately
unusual ascent/descent metrics remain unchanged. These synthetic fonts test
occupied ink geometry; they do not implement Myanmar OpenType shaping.

`NotoSansMyanmar-Regular.ttf` is the separate, unmodified real shaping fixture
(Noto Sans Myanmar 2.105). It contains Myanmar GSUB/GPOS/GDEF tables. Copyright
2018 The Noto Project Authors; distributed under SIL Open Font License 1.1,
included in [NotoSansMyanmar-OFL.txt](NotoSansMyanmar-OFL.txt). It is not covered
by the original rectangle fixtures' ISC license and is not regenerated by the
Python script.

Meson supplies the committed Noto fixture to all furigana tests. Strict band
snapshots disable OS font providers: tight cases use their synthetic coverage;
the default case uses bundled Pixel Operator Mono for Latin bases and bundled
Noto Sans Myanmar for readings. No font download or font installation is needed.
The new `furi-myanmar-shaping` test checks nonempty cmap glyphs, clustered shaping,
visible zero-advance marks and ink above/below the baseline, then tests the
original Myanmar gyaku/normal pair with top, center and bottom anchors, explicit
positions, margins, borders/shadows, and already sufficient line spacing.
Missing glyphs and empty annotation geometry are explicit failures, never skips.
